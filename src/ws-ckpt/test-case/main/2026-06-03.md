## 为什么加

main 此前已经有 OpenClaw 的 `detect/install/uninstall` 三件套适配脚本，但 **Hermes 适配只有 install/uninstall，缺一个只读探测（detect）入口**，无法在不改动环境的情况下回答「Hermes 集成是否就绪」。`99ba08a` 补齐了这块，并顺带让 `install-hermes.sh` 支持环境变量覆盖与 `DRY-RUN`（幂等、可在 CI / 无 root 下安全预演）。这是已合入 main 的能力，需要建立回归断言，防止后续重构把 detect 入口、manifest 登记、Makefile 安装、DRY-RUN 分支再次丢掉。

主要变更方向：

1. **新增 `scripts/detect-hermes.sh`（只读）**：检测 hermes CLI、`HERMES_HOME`、插件软链 / skill 回退、运行时二进制、adapter 源；退出码 `0=就绪 / 1=未装但可装 / 2=缺前置依赖`。
2. **`install-hermes.sh` 增强**：支持 `HERMES_HOME` / `HERMES_BIN` / `HERMES_SKILLS_DIR` 覆盖；新增 `ANOLISA_DRY_RUN=1` 干跑分支（只打印 `DRY-RUN:` 计划、不落地、退出 0）；`hermes plugins enable` 失败降级为 Warning 而非中断。
3. **`adapter-manifest.json` 登记 `detect` action** 指向 `scripts/detect-hermes.sh`。
4. **`Makefile` 安装 detect-hermes.sh**（`install -m 0755` 到 `ADAPTER_DIR/scripts/`）。
5. **`install-openclaw.sh` / `uninstall-*` 同步微调**（保持适配脚本族一致）。
