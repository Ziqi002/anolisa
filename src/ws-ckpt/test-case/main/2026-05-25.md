## 为什么加

v0.3.0 发布引入了三大变更方向：
1. **Plugin 架构**：新增 openclaw（TypeScript）和 hermes（Python）两个 agent 插件，以及配套的打包/安装/卸载脚本和 adapter-manifest.json
2. **构建系统重构**：新增 Makefile install 契约，RPM spec 支持插件安装，lib-discover.sh 路径发现库
3. **核心 daemon 修复**：bincode 序列化修复、diff 解析器增强（symlink/hardlink/mv）、SnapshotNotFound 错误语义改进、daemon 鲁棒性增强、live-mount 迁移逻辑、时区显示支持

本批测试确保以上所有变更的契约和结构完整性。
