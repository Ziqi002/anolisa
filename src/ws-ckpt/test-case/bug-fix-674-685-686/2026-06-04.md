## 为什么加

这三个 commit 修复三个独立但严重的 daemon 问题：

### #674：rsync 失败不应删除 workspace
旧代码 `error!` 后继续执行 `delete_subvolume` 和 `remove_symlink`，导致 rsync 失败时 workspace + 所有 snapshot 被删。改为 `bail!` 保留数据供重试。

### #685：write-locked workspace 从 state.json 消失
`collect_workspace_entries` 用 `try_read()` 跳过持有写锁的 ws，daemon restart 后该 ws 从 state 丢失。改为从 `path_to_wsid`（无锁）读取，不依赖 `RwLock` 状态。同时 `get_all_workspace_info` 改为 async `.read().await`。

### #686：seccomp 在 aarch64 上完全失效
硬编码 `TargetArch::x86_64` 导致 aarch64 上 `audit_arch` 不匹配，BPF filter 被内核忽略（syscall 全放行）。改为 `cfg(target_arch)` 动态选择 `TargetArch`。另外更新 deny-list：+pidfd family (4), -lookup_dcookie (kernel 6.6 已移除)。
