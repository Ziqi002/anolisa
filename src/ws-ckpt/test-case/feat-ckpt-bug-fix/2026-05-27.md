## 为什么加

feat/ckpt/bug-fix 分支包含 5 个修复，尚未合入 main，覆盖以下变更方向：

1. **死代码清理**（fc6c98e）：移除已废弃的 `btrfs_ops.rs` 过渡 re-export 层，确保 `btrfs_common` 直接被引用且编译不报错。
2. **fswatch CLOSE_WRITE 语义修复**（1f56d12）：修改 `WorkspaceWatcher` 使其在检测到 `CLOSE_WRITE` 时清除 writing 标志，避免 checkpoint 无限等待 quiescence。
3. **cwd 保护逻辑**（605e478）：当 cwd 在 workspace 内或其子目录时，hermes 插件的 checkpoint/rollback/config 操作必须拒绝执行，防止 inode 替换后 cwd 失效。
4. **skill delete 必须 --force**（d2382c1）：SKILL.md 文档更新，agent 执行 delete 命令时必须带 `--force` 跳过确认。
5. **插件自动加载**（353b595）：openclaw plugin.json 增加 `"activation": {"onStartup": true}`；hermes install 脚本调用 `hermes plugins enable`。
